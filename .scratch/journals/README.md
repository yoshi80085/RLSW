# 🧠 Bot journals — drop them here

The 🧠 REVIEW panel's **⬇ JSON** button writes `bot-journal-<timestamp>.json`.
Save it into **this folder**.

Why here: this directory is inside the repo, and the repo is the folder shared
with the AI editor — so a journal saved here can be read directly, in full, with
no copying and pasting. A journal is a few thousand decisions; the panel's
**📋 COPY SUMMARY** button is the version that fits in a message.

On Chromium the ⬇ button opens a real save dialog, so this folder can be picked
straight from it. Elsewhere it lands in Downloads and needs moving.

⚠️ These are throwaway evidence, not source. Delete them freely; do not let them
pile up in a commit the way `_to_delete/` did in `230ff8e`.
