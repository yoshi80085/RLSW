# Editable Bardbarian preview

Read CLAUDE_BARDBARIAN_INTRO_HANDOFF.md first. Edit previews/bardbarian-intro/ directly.
The exact saved user settings are alex-dial-in.json in that directory; timeline.js
imports them. Preserve that provenance when experimenting. Run npm test after edits.
Use npm run dev to preview; npm install is required on a fresh machine.
This package contains the scene and its dependencies, not the full game.
Production gameplay integration must happen in the original repository.
The context folder one level up holds reference copies of the repository handoffs.
