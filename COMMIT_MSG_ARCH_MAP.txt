🎯 THE CHECK IS THE POINT, NOT THE REWRITE
   A rewritten doc drifts again in a month — that is exactly what happened to
   the last one, and nothing could tell. src/engine/architectureCheck.mjs
   (`npm run test:arch`, wired into test:all) asserts the three claims a map
   makes that CAN be falsified:
     §1 every source module is named in the doc          — 157 modules
     §2 every file path the doc names exists             — 218 paths
     §3 every export the doc lists is really exported    — 502 exports
     §4 the doc is intact and keeps its load-bearing sections
   A module added without a row FAILS the suite. That is deliberate: the cost of
   documenting a file is paid when it is cheapest, by whoever has the context.

   ⚠️ PROVEN BY BREAKING IT, NOT BY WATCHING IT PASS. CLAUDE.md's rule is that a
   passing test is not evidence a rule is real, so all three arms were failed on
   purpose first: a new module with no row, a row renamed to a nonexistent file,
   and styleCommitDb — the real historical phantom — added to chords.js's export
   list. Each failed with the message a reader needs.

   📌 §3 reads only four-column rows. The first draft regexed whole lines and
   produced six false positives off the ui/ table's three-column prose, which is
   exactly how importcheck.mjs earned its deletion yesterday. The row shape is
   the gate.
